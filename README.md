# Kasalig bAI — AI-Powered Personalized Learning

## 1. Project Summary

Kasalig bAI is an AI-powered learning gap detection and recommendation system designed to help students identify their weaknesses, receive personalized learning materials, and track their academic progress. It also helps teachers monitor student performance and identify learners who may be falling behind.

## 2. Problem Statement

Students may struggle with identifying their specific learning gaps due to curriculum misalignment, limited personalized learning resources, and difficulties tracking academic progress. Teachers may also find it challenging to identify struggling students early. Kasalig bAI addresses these problems through AI-driven assessment analysis, personalized recommendations, and performance monitoring.

## 3. Target Users

* **Students:** Take assessments, identify learning gaps, access personalized learning materials, and monitor improvement.
* **Teachers/Instructors:** Monitor student performance, identify learning gaps, and detect students who may need additional support.

## 4. Core Features

* **Assessment Management:** Allows students to take quizzes and assessments.
* **Automated Grading:** Evaluates student answers and identifies mistakes.
* **AI Learning Gap Detection:** Analyzes assessment results to identify weak topics.
* **Personalized Recommendations:** Suggests learning materials and exercises based on identified weaknesses.
* **Progress Tracking:** Records student performance over time.
* **At-Risk Student Monitoring:** Helps teachers identify students who may be falling behind.
* **User Authentication:** Supports student and teacher accounts.

## 7. Setup Instructions

### Prerequisites

* Node.js and npm
* Java Development Kit (JDK)
* Git
* Access to the required API and database credentials

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Jaex10x/Kasalig-bAI.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Kasalig-bAI
   ```

3. Install frontend dependencies from the directory containing `package.json`:

   ```bash
   npm install
   ```

4. Configure the required environment variables using `.env.example`. Never commit actual API keys, passwords, or secrets.

5. Start the frontend development server:

   ```bash
   npm run dev
   ```

6. Start the Spring Boot backend separately, from its backend directory, using the project's configured build tool and instructions.
